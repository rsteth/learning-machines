# Learning Machines

Small, self-contained experiments for understanding machine learning. Mechanics and evidence live here; the companion website owns the writing, layout and controls.

## First experiment

[Attention and memory](experiments/attention-memory/README.md): **How much does a model need to keep?**

Requires Node.js 18 or newer, no dependencies or model downloads.

```sh
npm test
npm run experiment
```

This first entry is a teaching illustration, not an actual model experiment or benchmark. Future measured experiments should include their dataset, seed, environment and results, and be labelled separately.

Each experiment gets its own folder, runnable entry point, assumptions, sources and tests. No shared framework is required.
